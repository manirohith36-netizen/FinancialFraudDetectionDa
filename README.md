🚨 Financial Fraud Detection System

📌 Project Overview
    The Financial Fraud Detection System is a multi-page analytics and machine learning dashboard developed using Streamlit.

The project helps identify fraudulent transactions, analyze customer behavior, monitor high-risk locations, and predict fraud using machine learning techniques.

🎯 Objectives
    Detect fraudulent financial transactions
    Analyze transaction behavior
    Identify high-risk customers
    Monitor fraud by location
    Build a machine learning fraud prediction model
    Provide actionable insights through interactive dashboards

📊 Dataset Information
    Total Records: 50,000+
    Type: Financial Transactions
    Features:
    Transaction Amount
    Transaction Type
    Account Balance
    Device Type
    Location
    Merchant Category
    Previous Fraud Activity
    Daily Transaction Count
    Card Type
    Card Age
    Fraud Label
